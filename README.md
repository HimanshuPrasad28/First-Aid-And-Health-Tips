# 🩺 First Aid & Health Tips Website

A responsive and educational website providing essential **First Aid procedures**, **health resources**, and **safety tips** to promote awareness and preparedness for medical emergencies.  
Built using **HTML**, **CSS**, and **JavaScript**, this project serves as a learning resource for students and individuals interested in web development and public health education.

## 🩹 Introduction
**First Aid & Health Tips** is a multi-page educational website designed to help users understand how to handle medical emergencies through easy-to-follow guides, resources, and interactive content.  
It emphasizes quick access to **First Aid guides**, **training programs**, **health tips**, and **emergency contact tools**.

---

## 🎯 Purpose
- To educate users on essential first aid techniques.  
- To provide verified health resources and training opportunities.  
- To raise awareness of preventive healthcare practices.  
- To serve as a front-end web development project for practical learning.

---

## 🌍 Features
✅ Responsive multi-page design

✅ Dark mode toggle (saves user preference)

## 🧱 Website Structure
The website consists of multiple HTML pages:

| Page | Description |
|------|--------------|
| `index.html` | Homepage with introduction and contact form |
| `guides.html` | Step-by-step First Aid guides |
| `resources.html` | Health resources, infographics, and videos |
| `training.html` | Training & certification details |
| `quiz.html` | Health awareness quiz section |
| `locator.html` | Emergency locator tools |

Common assets:
- `styles.css` — Main stylesheet  
- `script.js` — Handles dark mode, animations, and search  
- `/images` — Contains logos and visuals

## 🧩 Development Process
1. **Planning & Wireframing** – Designed website layout and page structure.  
2. **Designing** – Selected color palette and typography for readability.  
3. **Coding** – Developed pages using semantic HTML, styled with CSS, and added interactivity with JavaScript.  
4. **Testing & Debugging** – Ensured responsiveness across devices and fixed styling/logic issues.  
5. **Deployment** – Uploaded to GitHub and deployed via Netlify.
